# 国际公共服务电话号码查询：设计说明

## 目标

新增“国际公共服务电话号码查询”工具。用户可以按国家/地区、类别、机构或关键词找到紧急服务号码，以及中国的政府便民服务、主流银行和全国性保险公司官方客服电话。

第一版覆盖中国、美国、加拿大、英国、法国、德国、日本、韩国、新加坡、澳大利亚和印度。国际部分以紧急服务号码为主；银行与保险目录仅覆盖中国，避免将跨国、地区化或业务线差异大的客服电话误作通用号码。

## 数据与核验规则

所有记录均为静态本地数据，包含：国家/地区、类别、机构名称、号码、简短说明、官方来源 URL 和核验日期。紧急号码须以政府、警察、消防、急救或驻外使领馆的官方页面为来源；中国银行和保险客服电话须以该机构官方网站或官方客服页面为来源。

数据中不收录个人号码、非官方聚合站、付费转接号码或无法验证来源的条目。每一条记录在页面可跳转至其来源页面。数据“核验日期”说明人工最后核验时间，不承诺号码永远不变。

## 分类与范围

1. 紧急服务：报警、火警、急救、综合紧急号码；所有首批国家/地区均提供。
2. 政府与便民：中国的官方常用便民与政务服务号码。
3. 银行客服：中国主流全国性银行的官方客服号码。
4. 保险客服：中国全国性保险公司的官方客服号码。

中国紧急服务会明确显示 110、119、120、122 等服务号码及用途。国际号码保留其当地拨号格式，并不自动加入国际区号，因为紧急号码通常必须在当地网络中直接拨打。

## 用户体验

页面默认展示中国并优先显示紧急服务。用户可切换国家/地区、点击类别标签或输入机构/号码关键词筛选。结果卡将显示号码、用途、机构、核验日期和“官方来源”链接；号码提供复制按钮与 `tel:` 直接拨打链接。

紧急类别顶部永久显示醒目提示：紧急危险请立刻拨打当地紧急服务，不要依赖网页加载、搜索或翻译。所有筛选和复制状态只在浏览器中处理；不上传查询内容。

## 数据与代码边界

新增独立 UMD 数据模块，导出国家、分类、电话号码记录和筛选/号码清理函数，可由浏览器与 Node 测试共同使用。页面控制器只负责渲染、筛选、复制反馈、语言切换与本地 UI 状态；不硬编码电话号码。

所有 UI 使用中文/英文文案；网站其他语言回退为英文。外部来源链接使用新标签页并加 `rel="noopener noreferrer"`。号码文本通过 DOM `textContent` 渲染，避免将目录数据插入 HTML。

## 错误与安全提示

本工具不是应急指挥或官方热线替代品。若号码不可用、所在地不在首批覆盖范围，或遇到生命/财产紧急危险，用户应直接联系当地紧急服务或官方机构。页面会提示号码可能因地区、业务和时间变化，关键情况需打开官方来源再次确认。

损坏的本地筛选状态将回退为中国与“全部”。不符合 `https:` 的来源链接不会被渲染为可点击链接；不符合电话号码字符集的记录在数据测试中失败。

## 验证标准

1. 首批 11 个国家/地区均有至少一条紧急服务记录；
2. 中国包含 110、119、120、122；
3. 中国银行和保险分类的每一条记录均有 HTTPS 官方来源与核验日期；
4. 所有号码仅包含数字、空格、`+`、`-`、`(`、`)` 或 `/`；
5. 数据筛选、电话号码复制、`tel:` 链接清理、JavaScript 语法、页面入口、国际化和 Git diff 均通过检查；
6. 号码数据在实现时逐项查阅官方来源并记录核验日期。

## 交付

功能完成后，数据模块、页面、测试、样式与入口将合并到 `main` 并推送。后续扩展国家、机构或类别只需添加经过核验的独立数据记录。
