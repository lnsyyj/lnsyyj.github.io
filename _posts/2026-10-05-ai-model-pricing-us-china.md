大模型产品的收费，主要分成两条线：**普通用户按月订阅，开发者按 API 用量付费**。订阅适合直接使用聊天、搜索、写作和办公功能；API 则适合把模型接进网站、客服、Agent 或内部系统。

中美市场的差别也不只是标价。美国主流产品的个人会员价格多在每月 20 美元上下，并提供更高额度的重度套餐；国内产品常见免费入口、会员权益与云平台 API 并行。开发者选模型时，则要看输入和输出 Token 的单价、充值方式、缓存折扣和实际效果。

> 下文金额按厂商公开价目列示，API 价格均按每 100 万 Token 计算。不同模型能力、上下文长度、区域、缓存和促销政策都可能不同，价格不能单独代表性价比。

## 个人使用：月费大多在 20 美元左右

| 产品 | 代表套餐 | 付费方式与说明 |
| --- | --- | --- |
| ChatGPT | Plus：$20/月 | 按月订阅；API 另行计费，目前 Plus 不提供年付 |
| Claude | Pro：$20/月；年付折合约 $17/月 | 年付 $200；Max 从 $100/月起 |
| Gemini | Google AI Pro：$19.99/月 | 还包含 Google 存储及部分 Gmail、Docs 等生态权益，套餐内容按地区而异 |
| Kimi | 多档会员 | 会员按月或按年订阅，额度与权益以官网实时页面为准 |

美国个人 AI 服务逐渐形成两个价格区间：约 **$20/月的常规会员**，以及 Claude Max 等 **$100/月起的重度套餐**。订阅通常买的是产品内的使用额度和功能，不等于 API 余额，也不代表无限调用。

国内会员套餐更依赖具体产品和权益。以 Kimi 为例，会员与开发者 API 是两套付费方式：会员用于 Kimi 产品内的功能和额度，API 用量则在开放平台单独结算。不要把会员套餐的额度直接当作 API Token 余额。

## API 怎么计费：输入、输出分开算

常见公式是：

**费用 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价**

1M Token 就是 100 万 Token。提示词、历史对话和传入的文档会计入输入；模型生成的内容计入输出。多数模型的输出单价高于输入单价，因此长回答、推理过程和 Agent 多轮调用会明显抬高账单。

下面列出几款代表模型的标准 API 价格，便于看清量级：

| 厂商与模型 | 输入 / 1M Token | 输出 / 1M Token | 计费提示 |
| --- | ---: | ---: | --- |
| OpenAI GPT-5.6 Sol | $4 | $20 | 缓存输入另有低价 |
| Claude Opus 5.5 | $4 | $20 | 缓存、批处理等有单独价格 |
| Claude Haiku 4.5 | $1 | $5 | 轻量任务成本更低 |
| DeepSeek V4.1 Flash | 高峰 $0.30；低峰 $0.15 | 高峰 $1.20；低峰 $0.60 | 缓存命中更便宜；费用从充值余额扣除 |
| DeepSeek V4 Pro | 高峰 $1.32；低峰 $0.66 | 高峰 $3.96；低峰 $1.98 | 高峰与低峰时段按官方时区计算 |
| 通义千问 qwen-max | ¥2.40 | ¥9.60 | 中国内地北京地域的公开价格；可用免费额度以控制台为准 |

美国厂商的 API 价目通常以美元展示，国内云平台则多以人民币计价。不同地区的端点、模型版本和服务等级也可能使用不同价格，因此实际接入前应以账号所在区域的控制台为准。

## 用同一份工作量比较账单

假设一次任务累计使用 **100 万输入 Token + 100 万输出 Token**，不计缓存、税费和其他服务费用：

| 模型 | 估算费用 |
| --- | ---: |
| GPT-5.6 Sol | $24 |
| Claude Opus 5.5 | $24 |
| DeepSeek V4.1 Flash | 高峰 $1.50；低峰 $0.75 |
| DeepSeek V4 Pro | 高峰 $5.28；低峰 $2.64 |
| 通义千问 qwen-max | ¥12 |

这组数字只能说明计费量级，不能直接得出模型优劣。模型能力、回答质量、上下文长度、延迟和工具调用表现不同；美元与人民币价格也没有在表中换汇。正式选型时，最好拿自己的提示词和任务做小规模测试，再估算月调用量。

## 充值、订阅、后付费分别适合谁？

- **包月会员**：适合直接使用官方网页或 App 的个人用户，费用固定，省去 API 接入和账单管理。
- **API 预充值**：适合个人开发者和用量不稳定的项目。DeepSeek 会从充值余额或赠送余额中按调用扣费，也提供峰谷价差；先充值、后按量扣费，比较容易控制预算。
- **云平台 API 账户**：适合已经在使用阿里云、腾讯云、火山引擎等服务的团队。平台通常提供按 Token 计费、免费额度、资源包或企业结算，具体规则按模型和地域变化。
- **企业合同**：适合有稳定的大规模需求、数据治理或服务等级要求的组织，可向厂商询价并确认并发、可用性和数据处理条款。

ChatGPT Plus、Claude Pro 等个人订阅通常不包含对应厂商的 API 费用。购买会员前要确认自己需要的是聊天产品，还是要在程序里调用模型。

## 中美价格差异怎么看？

从本文列出的公开价目看，国内云平台有不少低价模型和免费额度，DeepSeek 还按时段提供不同价格；美国厂商的旗舰 API 单价相对较高，但也有 Haiku 这类较低价模型。**国内模型整体更容易找到低成本的大规模调用选项**，而美国会员产品常见约 $20/月的清晰订阅档位。

不过，“国内一定便宜”或“美元模型一定更强”都不是选型结论。长上下文、缓存折扣、推理模式、联网搜索、图片和音频等功能会改变最终账单。企业评估时要把模型费、平台费、搜索或存储等附加费，以及人工复核成本一起算进去。

## 简单的选择建议

- 个人日常使用：先试免费版；确实需要更高额度或额外功能，再考虑会员。
- 偶尔开发或做原型：选可充值、按量扣费的 API，先给账户设预算并监控调用量。
- 客服、摘要、分类等高频任务：先用低价模型验证质量，不必默认调用旗舰模型。
- 复杂编程、分析和长流程 Agent：对比旗舰模型完成同一任务的成功率，再按“每个成功任务的总成本”选型。

大模型的竞争已经从单纯比较能力，转向能力、速度和成本一起比较。对用户来说，会员解决的是“方便地用”；API 解决的是“把模型接入自己的产品并按实际用量付费”。
