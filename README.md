# JiangYu

一个基于 GitHub Pages 与 Jekyll 的个人博客，包含轻量的本地小工具。

## 页面

- 首页：展示最新文章与工具入口
- 文章：Jekyll 原生文章列表；将 Markdown 文件放进 `_posts/` 即可发布
- 工具箱：收集实用的小工具
- JSON 格式化：支持格式化、压缩、校验及复制，所有内容仅在浏览器本地处理

## 写新文章

在 `_posts/` 创建文件，例如：

```md
---
layout: post
title: 我的新文章
description: 一句话摘要。
---

正文内容。
```

文件名使用 `YYYY-MM-DD-title.md` 格式。
